Cada escolha tem um motivo escrito.

Camada Tecnologia Por que esta
Linguagem Java 17 · Spring Boot 3.5.3 Tipagem forte e ecossistema maduro para a camada que guarda os dados da turma.
Banco de dados PostgreSQL 16 O modelo tem relação muitos-para-muitos e histórico auditável. Banco de documentos atrapalharia exatamente isso.
Versão do schema Flyway · 10 migrations O banco evolui por arquivos numerados e versionados. Migration já aplicada nunca se edita.
Aplicativo Ionic 8 + Angular 20 Um código só para Android e navegador. Componentes standalone e signals.
Empacotamento Capacitor 8.5 Transforma o app em APK instalável, com acesso a notificação local.
Testes JUnit 5 · Postgres embutido · Karma Testes de servidor rodam contra um Postgres de verdade, sem exigir serviço instalado.
Hospedagem Render (API) · Neon (banco) Plano gratuito. O app foi desenhado assumindo que o servidor hiberna.
Produtividade Git/GitHub · Figma · Claude Code Versionamento, protótipo de telas e programação assistida — com diário de decisões no repositório.
Não ler a tabela. Apontar 3 linhas e comentar. A linha do PostgreSQL é a que responde "por que não Firebase", pergunta provável. Versão longa: o app precisa ligar material a prova numa relação muitos-para-muitos, e guardar histórico de quem editou o quê. Banco relacional faz isso naturalmente; banco de documentos te empurra para duplicar dados, e aí o histórico e as regras de isolamento ficam frágeis. A linha de produtividade menciona programação assistida. ISSO É DELIBERADO E VOCÊ DECIDE SE MANTÉM. O argumento para manter: o repositório tem um diário com 38 entradas datadas registrando cada decisão, quem decidiu e por quê — inclusive as que foram revertidas. Isso é mais transparência do que a maioria dos projetos apresenta, e as decisões de arquitetura são defensáveis uma a uma, que é o que a banca vai testar no Q&A. Se perguntarem sobre a hospedagem gratuita: o plano dorme com 15 minutos sem uso. Isso não foi descoberto na véspera — o aviso da véspera é agendado no próprio celular justamente para não depender do servidor estar acordado.
